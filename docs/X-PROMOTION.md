## 发布步骤

1. 打开上面的 X compose 链接（建议用英文主帖；中文主帖可另发，或作为回复）。
2. 登录 X，在主帖附上 `assets/x-launch.png`。
3. 发布后 **Pin** 主帖，然后依次回复 4 条，分别附上对应图片。
4. 在回复里只 @ 一次 `@deepseek_ai`（主帖已包含）；不要重复 @ 或批量骚扰。
5. 发布后 1–2 小时内回复评论和私信；把有价值的反馈转成 issue。
6. npm 发布后，在评论区补一条：
   `Now on npm: dsh plugin --profile web add dsh-workspace-tags`
   以及 REALOIYO 索引 URL（发布后 6 小时内通常收录）。
7. 不建议删除/反复重发同一条内容；X 对重复链接和过度 @ 会限流。

## 时间和节奏

- 建议时间：北京时间 **10:00–11:00** 或 **20:00–22:00**，工作日优先。
- 主帖 + 4 条回复即可；不要一天内多次转发同一条。
- 发布后观察 X Analytics 的 impressions / link clicks / profile visits；如果 24 小时互动低，换一个角度（例如“为什么工作区需要标签”）再发一条，而不是重复原文。
